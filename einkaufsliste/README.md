# Einkaufsliste

Einkaufsliste mit Mengen (Stück, Gewicht, Volumen), Notizen und Abhaken – als Dashboard-Karte,
in der Seitenleiste, per Sprachsteuerung und als Handy-App, die auch ohne Empfang funktioniert.

Nach dem ersten Start: Home Assistant neu starten und unter **Einstellungen → Geräte & Dienste →
Integration hinzufügen → „Einkaufsliste“** einrichten. Details im Reiter „Dokumentation“.
